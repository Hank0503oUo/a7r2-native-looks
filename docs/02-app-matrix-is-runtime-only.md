# 02 實驗：App 設定的 RGB 矩陣會不會留在機身？

日期：2026-10-25。App：膠片工坊 0.3.4 的測試版。

## 做法

1. **套用一個好辨認的測試濾鏡。** 在 App 裡選「紅藍交換」，矩陣係數刻意用了罕見的數字：`13,17,994 / 19,987,18 / 996,11,17`。
2. **讓 App 退出時不清除。** 這個測試版在選到測試濾鏡時，退出 App 不會清除矩陣和曲線（跳過 resetHook）。
3. **退出 App，看一般拍攝模式的顏色。**
4. **比對設定資料。** 用 updater shell 唯讀讀取 nflasha2（設定）和 nflasha4（MPR Flash Backup），和寫入前的整機備份比對。

## 結果

- **顏色已恢復。** 退出 App 後，一般拍攝模式的顏色馬上恢復正常。
- **設定檔沒有變動到矩陣。** `Backup.bin` 有 29 項改變，都是計數、時間和使用者操作，例如檔案編號加一，沒有任何一項是矩陣。
- **原始資料裡也找不到。** 在 `Backup.bin`、`Backup.bak`、nflasha2 和 nflasha4 裡搜尋測試係數，int16、int32、大小端都試過，整組或只搜第一列都沒有命中。

## 結論

- **App 設的矩陣只存在執行期。** 透過 `setRGBMatrix` 設的矩陣不會被保存，App 結束時平台會自己重設，即使 App 本身沒有清除也一樣。
- **擴充 gamma 表也一樣。** 這和韌體分析一致：它本來就只是一個記憶體指標。
- **只能從原生設定下手。** 想讓顏色在一般模式、PC 遙控和 Monitor+ 下生效，不能靠 App 寫設定，只能改原生設定本身。下一步就是找原生風格自己的矩陣存在哪裡，見 [03](03-native-matrix-table.md)。

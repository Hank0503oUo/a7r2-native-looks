# 05 v2：用 RAW+JPEG 色卡擬合（2026-11-01）

## 模型

同一張照片的 RAW 和機身 JPEG 之間，可以寫成：

```
JPEG = T_s( M_s · P · raw )
```

| 符號 | 意義 |
|---|---|
| `raw` | 白平衡後的線性感光元件 RGB（rawpy，使用相機白平衡） |
| `P` | 感光元件到工作色彩空間的 3x3，所有風格共用 |
| `M_s` | 該風格在 `0x00030001` 表裡的矩陣，拍攝當下寫在相機裡的值，已知 |
| `T_s` | 該風格的色調曲線，R、G、B 共用一條單調曲線 |

`P` 和每個風格的 `T_s` 交替估計（[`native_looks.fit_model`](../calibration/native_looks.py)），每張照片的殘差約 5 到 16 個碼值（0 到 255 的尺度），S-Log2 約 19。

## 目標怎麼來

目標是「這個場景用官方 LUT 處理後應該長怎樣」，從同一張 RAW 算出：

1. **RAW 轉 XYZ。** 用 rawpy 和 LibRaw 的相機矩陣。
2. **XYZ 轉 BT.2020。** F-Gamut 和 L-Log 用的都是 BT.2020 原色、D65。
3. **轉成廠商的 Log 編碼：**
   - **F-Log2：** `x ≥ 0.000889` 時為 `0.245281·log10(5.555556x + 0.064829) + 0.384316`，否則為 `8.799461x + 0.092864`。
   - **L-Log（Reference Manual V1.9）：** `x ≤ 0.006` 時為 `8x + 0.09`，否則為 `0.27·log10(1.3x + 0.0115) + 0.6`。
4. **套官方 LUT。** 富士用 GFX ETERNA 55 3D LUT v1.00 的 33 格 `FLog2_to_<風格>`，徠卡用 `Classic_Rec709`、`Natural_Rec709`，以三線性內插。

曝光：把色卡白色的 Y 值（99.5 百分位）對到 0.9 的反射率。

## 擬合

每個槽只解一個 3x3（[`fit_looks.py`](../calibration/fit_looks.py)）：

1. **線性最小平方。** 把目標經 `T_s` 的反函數拉回線性，限制每一列加總為 1，讓灰色維持中性。目標亮度改用原廠矩陣算出的亮度，所以只改色度、不改明暗。
2. **Levenberg–Marquardt 微調。** 線性解只是起點。接著對 6 個自由係數（每列 2 個，第 3 個由加總為 1 決定）做 LM，讓色度誤差最小；誤差是在經過該風格色調曲線之後的顯示畫面上計算。
3. **量化。** 四捨五入到 1/1024，再修正對角線，讓每列的整數加總剛好等於 1024。

有幾類資料不納入擬合：
- 已經裁切的色塊（目標任一通道超過 0.995 或低於 0.005）。
- 最暗的 5% 色塊。
- S-Log2 的照片，因為它的曲線和其他風格差太多。

## 拍攝方法

起初用米色牆拍的 RAW，色彩太少：約 9800 個區塊中，只有幾十個有明顯色彩，3x3 解不穩。所以改成拍螢幕上的色卡。

1. **產生色卡。** 用 `calibration/make_chart.py` 產生 `color-chart-1920x1080.png`。它有 144 塊：16 個色相乘 6 種飽和度和亮度、16 個膚色和記憶色、32 階灰階。
2. **在螢幕上全螢幕顯示，然後拍攝。** 建議在暗室拍，相機設定：
   - RAW+JPEG。
   - **L 尺寸。** M 或 S 尺寸要先縮放才能和 RAW 對齊。
   - **鏡頭失真校正「關」。** 開著會讓 JPEG 和 RAW 的幾何對不上。
   - 固定曝光，例如 1/13 秒、f/5.6、ISO 100。
   - 固定白平衡。
3. **每個要擬合的風格和 PP 各拍一張。** 清單格式見 [`calibration/example-shots.tsv`](../calibration/example-shots.tsv)。
4. **記下拍攝當下相機裡的矩陣表。** 用 `table.py extract` 讀出來。`build_model.py --table` 需要它，因為模型要知道每張照片是用哪個 `M_s` 拍的。

JPEG 和 RAW 的對齊方式：先把 JPEG 縮放到 RAW 的裁切尺寸，再用梯度相關找整數位移，只用畫面中央 70%。

```sh
pip install -r requirements.txt
python calibration/build_model.py --photos DIR --shots calibration/example-shots.tsv --table table_when_shot.bin -o model.pkl
python calibration/fit_looks.py --model model.pkl --base my_original.bin --plan calibration/v2-plan.json \
    --fuji-luts DIR_WITH_FLog2_cubes --leica-luts DIR_WITH_Leica_cubes --compare looks/v1.json -o looks/v2.json
```

用 2026-11-01 那組照片執行上面兩步，得到的矩陣和誤差與 `looks/v2.json` 完全相同。

## 還沒做的事

- **寫入後的實拍驗證。** 要用寫入後的實拍和預測比對；日光下的效果也要確認，因為擬合用的是螢幕光源。
- **曲線部分。** 這張表只有矩陣，LUT 的曲線和只針對特定色相的扭曲做不出來。要在機內得到完整的 LUT 效果，只能用機內 App 直接處理 JPEG。
